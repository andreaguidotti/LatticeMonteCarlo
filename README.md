# [LatticeMC]

Three Monte Carlo studies of statistical and lattice field theory systems.

## Modules

- **2D Ising model** — determination of critical exponents (γ/ν, ν) and 
  critical temperature via cluster (Wolff) update and finite-size scaling.

- **Quantum particle on a circle** — topological susceptibility of a particle 
  on a ring in the presence of a confined magnetic field, sampled via 
  Metropolis and Parallel Tempering, with a reweighting scheme to access 
  rare topological sectors at high temperature.

- **3D Z2 gauge theory** — static potential and string tension in the 
  confined and deconfined phases, extracted from Wilson loop measurements.

Each module includes Monte Carlo simulation code and the corresponding 
data analysis code (Jackknife/Bootstrap statistics).
